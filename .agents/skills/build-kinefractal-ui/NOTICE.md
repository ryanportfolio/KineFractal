# Provenance

Built on 2026-09-28 with `forge-repo-ui-skill`. The rules are original wording written for this repository. No text, scripts or datasets were copied from the sources below; they were read at their `main` branch on that date.

Ideas adapted:

- [ConardLi/garden-skills](https://github.com/ConardLi/garden-skills) `skills/web-design-engineer` (MIT): extension / preserve / overhaul modes, preserve-improve-remove sorting, fix order from function to recomposition, protected contracts.
- [addyosmani/web-quality-skills](https://github.com/addyosmani/web-quality-skills) `skills/accessibility` (MIT): keyboard walk plus accessibility tree, "an automated score is not conformance", auditing without a reload that drops state.
- [vercel-labs/web-interface-guidelines](https://github.com/vercel-labs/web-interface-guidelines) `command.md` (MIT): `aria-live="polite"` for async updates, target sizes, one hit target per checkbox and label, focus not hidden by overlays, dark native controls, busy labels with "…", no dead ends.
- [practicalswan/agent-skills](https://github.com/practicalswan/agent-skills) `frontend-design` (MIT AND Apache-2.0): focus return after dialogs, stale state, reporting evidence and limits.
- [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) `frontend-ui-engineering` (MIT): error-with-retry and permission states.
- [anthropics/skills](https://github.com/anthropics/skills) `frontend-design`: one wording per call to action.

Rejected: new palette or type-system generation (anthropics frontend-design, nextlevelbuilder/ui-ux-pro-max), React-only rules, and browser acceptance only on request (conflicts with `CLAUDE.md`).

Written for this repository with no outside source: visible account state, return to the starting page after sign-in, site ownership of `charts.html`, and the site-mode / local-mode split.
